Arr Refresh

In Sonarr or Radarr, add a Webhook connection (Settings > Connect > + > Webhook):

  • URL: /ArrRefresh/Webhook
  • Method: POST
  • Headers: key Authorization, value MediaBrowser Token="<API key>", using a key from Dashboard > API Keys
  • Triggers: On File Import, On File Upgrade, On Rename, On Movie/Series Delete, On Movie/Episode File Delete. Leave the "File Delete For Upgrade" triggers off: they fire before the new file is in place.

Then turn off "Update library" on any Emby/Jellyfin connection in the same app, so changes are not sent twice.

One per line: the path as Sonarr/Radarr see it, =>, the path as Jellyfin sees it. Leave empty when both mount the media at the same path.
When the Meilisearch plugin is installed, items this plugin adds or changes become searchable within seconds instead of at that plugin's next full reindex. Uses that plugin's own connection settings.
